# iteasy

Консольный скрипт на Python: последовательно качает указанный URL 10 раз и считает скорость скачивания. Вывод в терминале оформлен через [Rich](https://github.com/Textualize/rich).

## Требования

- Python 3.9+
- Зависимости из `requirements.txt`:
  - **rich** — цветной вывод, таблица результатов, progress bar

## Установка

```bash
python -m venv .venv
```

Windows (PowerShell):

```powershell
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

Linux / macOS:

```bash
source .venv/bin/activate
pip install -r requirements.txt
```

## Запуск

```bash
python download_speed.py https://example.com/large-image.jpg
```

Пример с тяжёлой картинкой с российского ресурса (~1.4 МБ, hd-foto.ru):

```bash
python download_speed.py https://hd-foto.ru/sunflowers/01.jpg
```

## Что делает скрипт

1. Принимает адрес ресурса (URL) аргументом командной строки.
2. Делает **10 запросов подряд**, дожидаясь полного ответа на каждый.
3. Считает среднее время одного запроса и суммарный объём скачанных данных.
4. Печатает скорость скачивания в консоль (таблица + итоговая панель).

## Единицы измерения

| Метрика | Единица | Пояснение |
|--------|---------|-----------|
| Время запроса | с | секунды |
| Объём данных | МБ | мегабайты, **1 МБ = 1024 × 1024 байт** |
| Скорость скачивания | **МБ/с** | мегабайты в секунду (суммарный объём / суммарное время всех 10 запросов) |
